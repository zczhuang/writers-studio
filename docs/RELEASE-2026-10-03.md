# Writer's Studio — October 3, 2026

## A new story atlas

- An illustrated storybook welcome, warm paper colors, and four distinct writing worlds shape the new home screen.
- Daily missions invite the writer to finish one piece, write 100 words, and try two modes. Progress comes from saved writing and follows the local calendar day.
- An adventure trail shows five XP ranks, current progress, and the next milestone.
- Each world's completion counts unique prompts; repeats do not inflate the journey.
- A seven-day words view makes writing activity visible with encouraging feedback.
- A new achievement cabinet shows earned medallions, unlock dates, and progress toward the next three goals.
- Results celebrate XP gained and new ranks, show daily mission progress, and connect the next revision to a specific writing skill.

## Progress and privacy

- Existing writing, earnings, and progress keep the same browser storage key. The v2-to-v3 migration adds coaching memory and craft progress without starting a new account.
- Coaching memory is stored locally. When the Gemini coach is enabled, selected derived context is sent with a submitted piece to personalize feedback.
- The app remains a static browser app with local scoring available when Gemini is unavailable.

## Revision rewards

- Revising a piece updates its journal entry and adds a small XP bonus.
- Only a higher-tier revision of an unpaid reward from the same local day can add earnings, within the daily cap.
- Paid, closed, and earlier-day rewards stay unchanged while the writer can still revise for practice.

To reproduce the automated checks from the project root after installing dependencies, bundle the TypeScript test imports with the Rolldown binary included by Vite, then run Node's test runner:

```bash
npm run build
npm run lint -- --max-warnings=0
task_test_dir="$(mktemp -d)"
node_modules/.bin/rolldown scripts/revision-policy.test.mjs --platform node --format esm --file "$task_test_dir/revision-policy.test.mjs"
node_modules/.bin/rolldown scripts/progression.test.mjs --platform node --format esm --file "$task_test_dir/progression.test.mjs"
TZ=America/New_York node --test "$task_test_dir/revision-policy.test.mjs" "$task_test_dir/progression.test.mjs"
```

Raw research files `docs/_craft_design_raw.json` and `docs/_synthesis_raw.json` remain local and are not proposed for GitHub.
